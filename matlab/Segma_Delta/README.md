# Sigma-Delta Modulator Design Exploration

This section documents the design, implementation, and evaluation of different Sigma-Delta Modulator architectures for the MIMO Beamforming Transmit Chain.

The investigated architectures include:
- **EFB (Error Feedback):** First-order architecture exploration.
- **CIFB (Cascade of Integrators with Feedback):** Architecture implementation and evaluation.
- **MASH (Multi-Stage Noise Shaping):** Multi-stage architecture exploration.
- **Third-Order EFB:** An attempted higher-order implementation that was explored but did not achieve the intended design objectives.

The section includes MATLAB/Simulink models, simulation experiments, and performance analysis.
