# Post-DFT Verification and Formal Equivalence

This section documents the post-DFT verification stage of the MIMO Beamforming Transmit Chain.

## Contents

- **Logs:** Execution logs generated during post-DFT verification and analysis.
- **Reports:** Formal equivalence checking and verification reports.
- **Formality SVF:** Setup Verification Files used to guide formal equivalence checking, if applicable.
- **Formality Scripts:** Scripts and setup files used to configure and execute formal verification.

## Objective

To verify the functional equivalence of the DFT-inserted design against the corresponding reference design, ensuring that scan insertion and DFT transformations preserve the intended functional behavior.

## Tools

- Synopsys Formality
- Synopsys Design Compiler
