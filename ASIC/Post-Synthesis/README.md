# Post-Synthesis Verification and Formal Equivalence

This section documents the post-synthesis verification and formal equivalence checking stage of the MIMO Beamforming Transmit Chain.

## Contents

- **Logs:** Execution logs generated during post-synthesis and formal verification runs.
- **Reports:** Formal verification and analysis reports, including equivalence checking results.
- **Formality SVF:** Setup Verification File (SVF) generated during synthesis and used to guide formal equivalence checking.
- **Formality Scripts:** Scripts and setup files used to configure and execute formal equivalence checking.

## Tools

- Synopsys Formality
- Synopsys Design Compiler

## Objective

To verify functional equivalence between the RTL design and the synthesized netlist, ensuring that synthesis transformations preserve the intended design behavior.
